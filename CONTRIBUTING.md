# Contributing

Commits contain only what is needed to clone, set up and run the kit: source code, licence-cleared assets with provenance, small authored samples, setup documentation, tests and licences.

Keep these out of commits:

- Absolute or machine-specific paths. Use relative paths, command-line options or environment variables.
- Working notes, prompts, logs and other material that is not part of the product.
- Datasets, recordings, downloaded model weights and third-party assets whose licence does not allow redistribution.

Every bundled asset needs a recorded source and licence.
